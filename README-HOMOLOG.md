# Histórico do pacote de homologação

> **Documento histórico — não é um procedimento de instalação vigente.**

Este arquivo registrava as instruções de integração usadas na homologação inicial de segurança, CEP e temas sazonais. A integração foi concluída e os arquivos correspondentes já fazem parte da estrutura atual do projeto.

Não substitua o repositório por um pacote parcial nem siga as antigas instruções de cópia manual deste documento.

Para entender a arquitetura e a operação atuais, consulte:
- `README.md` — estrutura e arquitetura atual.
- `SYNC_ESTOQUE.md` — sincronização, fontes e horários.
- `docs/HOMOLOGACAO.md` e demais relatórios em `docs/` — registros históricos e evidências de homologação.
